픽셀 트래커 — 전체 페이지 디자인

픽셀네트워크 스트리머 29명의 방송을 기록하는 개인용 팬사이트. 확정된 시안 B(화이트) 시스템을 5개 페이지 전체에 적용한 PC·모바일 반응형 설계입니다. 모든 데이터는 실제 채널 정보(2026-07-20 수집) 기준이며, 라이브 상태만 예시입니다.

디자인 토큰
